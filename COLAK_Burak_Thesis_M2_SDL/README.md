## Repository Structure

- `/data`
    - `/ICLE_Corpus`
        - `/All_Learners`: Contains CSV, Numbers, and R-scripts for the full dataset.
        - `/Romance_vs_Germanic`: Contains comparative datasets, R-scripts, maps, and specific MCA analysis files.
            - `/MCA`: Contains specialized MCA R-scripts and associated maps.
    - `/Google_Forms`
        - `/Test_1`: Raw data (CSV), original questionnaire (PDF), and results (PDF).
        - `/Test_2`: Raw data (CSV), original questionnaire (PDF), and results (PDF).
        - `/CSVs`: Combined CSV files for both tests.
        - `Consent_Form`: Participant consent documentation.
        - `Script`: Analysis scripts for the questionnaire data.
        - `Charts_and_Bar`: Visualization exports.

- `/scripts`: Comprehensive R-scripts used for data processing and modeling.
- `/figures`: High-resolution versions of the charts and graphs presented in the thesis.
